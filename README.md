# SQL Data Analysis – Ecommerce Database

## 📌 Project Overview
This project demonstrates SQL data analysis using a custom Ecommerce database.  
The database includes Customers, Products, Orders, and Order_Items tables.

## 🛠 Tools Used
- MySQL
- SQL

## 🗂 Dataset
Custom Ecommerce_SQL_Database created manually using SQL.

## 📊 SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- INNER JOIN
- Subqueries
- Aggregate Functions (SUM, AVG)
- View Creation
- Index Optimization

## 📈 Key Analysis Performed
- Total revenue per product
- Customer total spending
- Revenue by category
- Top spending customer
